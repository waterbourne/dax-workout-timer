# iPad-Optimized Design Rubric (iOD)

## Problem Statement
Current agent outputs are optimized for mobile phones (brief, compact) but underutilize iPad screen real estate. Users want more substantial content with better visual hierarchy while maintaining engagement.

## Design Principles for iPad

### 1. Visual Hierarchy
- Use headers, sections, and whitespace
- 3-5 distinct visual sections per message
- Clear scanability — user should grasp structure in 2 seconds

### 2. Content Depth
- 2-3x word count vs mobile (but structured)
- Each section = one discrete idea
- Use bullets, emojis as visual anchors

### 3. Engagement Mechanics
- Interactive elements (checkboxes, challenges)
- Progressive disclosure (expandable concepts)
- Visual progress indicators

## iOD Scoring (Lower is Better)

Target: 20-40 (excellent iPad-optimized content)

```
START: 100

## LAYOUT BONUSES (subtract)
✓ Has clear header/title:                    -10
✓ Uses section dividers (--- or whitespace):  -10
✓ Visual emoji anchors (3+):                 -10
✓ Bullet/checkbox formatting:                -10
✓ Progress indicator or challenge:           -10
✓ Callout box (tip/warning/note):            -10
✓ 3-5 distinct sections:                     -15

## CONTENT BONUSES (subtract)
✓ 80-150 words (substantial but scannable):  -20
✓ One concept per section:                   -10
✓ Ends with actionable item:                 -10
✓ Includes "why this matters" explanation:   -10

## PENALTIES (add)
✗ Wall of text (no breaks):                  +20
✗ No visual hierarchy:                       +20
✗ Exceeds 200 words:                         +15
✗ Multiple unrelated concepts:               +15
✗ Mobile-style brevity (<50 words):          +15
```

## Example: Dax Before → After

### Before (Mobile-Optimized)
```
💪 Push, squat, hold.

Push-ups: 3×12
Squats: 3×15
Plank: 3×45s

12 minutes.

Full body in three moves.
```
**iOD Score: 85** (wall of text, no visual hierarchy, underutilizes space)

### After (iPad-Optimized)
```
💪 MONDAY: PUSH-FOCUSED FULL BODY

🎯 TODAY'S TARGET
Complete 3 rounds with minimal rest between exercises.

📋 THE CIRCUIT
□ Push-ups: 3 sets × 12 reps
□ Air Squats: 3 sets × 15 reps
□ Plank Hold: 3 sets × 45 seconds

⏱️ TIMING
12 minutes total | 60 sec rest between rounds

🔥 WHY THIS WORKS
This combo hits every major muscle group. Push-ups build chest/shoulder strength while squats engage your largest muscles (glutes/quads). The plank locks in core stability between movements. Three rounds creates enough volume for strength adaptation without overtraining.

✅ TRACK IT
Rounds completed: ___/3
Hardest exercise: ___
Energy level (1-10): ___
```
**iOD Score: 25** (sections, hierarchy, depth, interactivity)
